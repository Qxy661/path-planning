# 02 · 全局规划算法（A* / RRT / RRT*）

> 全局规划：已知地图，规划从起点到终点的最优/可行路径。
> 两类方法：图搜索（A*）和采样（RRT/RRT*）。
> 配套代码：`algorithms/astar.py`、`algorithms/rrt_star.py`。

## 一、图搜索类：A*

### 原理
```
f(n) = g(n) + h(n)
g(n)：起点到 n 的实际代价
h(n)：n 到终点的估计代价（启发式，如曼哈顿距离）
```

A* 优先探索 f 最小的节点（既走了不少路、又离终点近的节点），**"有方向地"朝终点推进**。

### 为什么 A* 快（vs Dijkstra）
- **Dijkstra**：只按 g(n)（已走距离）扩展，向四周盲目扩散
- **A***：按 f(n) = g+h（加了启发式），定向朝终点

### 关键性质
- **最优性**：h 一致（admissible）时，保证找到最优路径
- **完备性**：有路径则必能找到
- **适用**：静态已知地图，低维

### 实现要点（对应 astar.py）
```python
open_heap = [(0, start)]      # 优先队列按 f 排序
while open_heap:
    current = heappop(open_heap)   # f 最小
    if current == goal: 回溯路径
    for neighbor in 邻域:
        tentative_g = g[current] + step_cost
        if tentative_g < g[neighbor]: 更新并入堆
```

## 二、采样类：RRT / RRT*

### RRT（Rapidly-exploring Random Tree）
```
随机采样 → 找最近节点 → 向采样点步进 → 扩展树
```
- **原理**：随机探索空间，逐步构建树直到到达终点
- **特点**：快，适用于高维/复杂环境
- **缺点**：不保证最优（路径可能曲折）

### RRT*（优化版）
在 RRT 基础上加 **rewiring**（重布线）：
```
1. 新节点加入后，检查附近节点
2. 若通过新节点到某节点代价更小，则更新父节点
3. 渐近最优（节点数→∞时，趋于最优）
```

### 关键性质
- **概率完备性**：样本足够时，找到路径的概率 → 1
- **渐近最优**（RRT*）：收敛到最优解
- **适用**：高维、复杂环境、难建模空间

## 三、A* vs RRT（面试/科研常问）

| 维度 | A* | RRT |
|---|---|---|
| 方式 | 图搜索（需栅格化）| 随机采样 |
| 最优性 | 保证 | 不保证（RRT* 渐近最优）|
| 完备性 | 分辨率完备 | 概率完备 |
| 复杂度 | 与图大小相关 | 与采样数相关 |
| 高维 | 差（状态爆炸）| **好**（采样不受维度影响）|
| 场景 | 静态已知低维 | 高维/复杂/动态 |

**怎么选**：
- 地图已知 + 要最优 + 低维 → **A***
- 高维 + 复杂 + 只要能到 → **RRT**
- 高质量路径 → **RRT***

## 六、全局规划在 Nav2 中的角色

```
目标点 → 全局规划器(A*) → 全局路径（点序列）
                            ↓
                  局部规划器(DWA) 跟随 + 避障
```

Nav2 默认全局规划器就是 A* 变体（NavFn），
**手写 A* 替换它就是"探索应用"**（对比手写 vs 现成）。
