# 10 · 前沿探索自主建图（Frontier-based Exploration）

> 机器人**全自主**探索未知环境：自动检测"未知区域边界"（前沿），主动导航过去，地图从空白自动生长。
> 这是从"手动遥控建图"到"自主建图"的能力跃迁——导航系统落地能力的直接证明。

## 一、为什么做

常规建图（`explore_laser.py` 墙壁跟随 / 手动遥控）是**被动**的：机器人按预设轨迹走，走到哪建到哪。
前沿探索是**主动**的：机器人自己"看到哪里还没探索，就去哪里"——这才是真正的自主性。

> 调研（2026-08）确认：前沿探索是高质量自主建图的标准能力，explore_lite / AniArka / roadmap_explorer 均为代表作。

## 二、原理

```
前沿单元 = 空闲格(0) 且 4 邻域含未知格(-1)  —— "已探索区域的边缘"
连通域聚类 → 前沿区域（一个个"待探索的口子"）
贪心选择 → 距当前位姿最近的前沿区域质心
NavigateToPose 导航过去 → 到达后重新扫描 /map → 新的前沿出现
循环直到无前沿 = 建图完成
```

## 三、架构（SLAM 模式）

```
Gazebo 世界
  ↓
Cartographer（live SLAM）── 发布实时 /map + map→odom 定位
  ↓
Nav2（navigation_launch，无 map_server/amcl）── costmap 直接用 SLAM 的 /map
  ↓
frontier_explore.py（Python）── 前沿检测 → 聚类 → 贪心导航 → 循环
```

**关键**：SLAM 模式下不需要 AMCL（Cartographer 自带定位），Nav2 只需 planner/controller/bt_navigator。

## 四、核心实现（`robot/frontier_explore.py`）

```python
# 前沿检测：空闲格 邻接 未知格
free = (data >= 0) & (data < 50)   # Cartographer 空闲=低概率(0-49)
unknown = data < 0
frontier |= free & np.roll(unknown, (dy, dx), axis=(0,1))  # 4 邻域

# 连通域聚类（BFS）
```

## 六、踩坑记录（本模块的真实收获）

| # | 问题 | 解决 |
|---|---|---|
| 1 | Cartographer 地图无 0（空闲）值——空闲是概率值 31-49 | 前沿检测用 `0≤值<50` 判空闲 |
| 2 | 手写 A* 插件把未知格(255)当障碍 → 无法探索 | 插件加 `未知格可通行`（与 Nav2 allow_unknown 一致）|
| 3 | 前沿质心落在墙上 → 导航死等 | 质心偏移到已知空闲侧 + 90s 超时取消 |
| 4 | SLAM 模式 A* 插件与动态 costmap origin 交互不稳 | 自主探索用 Nav2 默认 NavFn（A* 插件用于静态地图导航，已另验证）|

## 七、用法

```bash
# 1. 启动 Cartographer（live SLAM）
ros2 launch turtlebot3_cartographer cartographer.launch.py use_sim_time:=True

# 2. 启动 Nav2（SLAM 模式，无静态地图）
ros2 launch nav2_bringup navigation_launch.py \
  params_file:=robot/config/nav2_navfn_params.yaml use_sim_time:=True autostart:=True

# 3. 启动前沿探索
python3 robot/frontier_explore.py
```
