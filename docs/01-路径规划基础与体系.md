# 01 · 路径规划基础与体系认知

> 从"只会算法"到"懂系统"的关键一章。
> 先建立体系认知（算法在导航系统的位置），再深入具体算法。

## 一、核心思维转变

```
之前：路径规划 = A* / RRT / DWA（一堆算法）
现在：路径规划 = 导航系统的一个环节，算法是零件
```

**专业人士和工具使用者的区别**：
- 工具使用者：会调 plannerAStar(地图, 起点, 终点) 出路径
- 专业人士：知道 A* 为什么快、在系统里扮演什么角色、怎么和定位/控制配合

## 二、导航系统全景（体系认知）

```
完整导航系统（不是单算法！）
┌─────────────────────────────────────┐
│  建图 SLAM：怎么得到地图             │
│    → 激光SLAM / 视觉SLAM / 栅格地图  │
├─────────────────────────────────────┤
│  定位 AMCL：怎么知道"我在哪"         │
│    → 粒子滤波（激光匹配）            │
├─────────────────────────────────────┤
│  全局规划：怎么走（大方向）          │
│    → A* / RRT* 在全局地图            │
├─────────────────────────────────────┤
│  局部规划：怎么避障（实时）          │
│    → DWA / TEB 速度控制              │
├─────────────────────────────────────┤
│  控制：怎么执行                      │
│    → PID / MPC 跟踪轨迹              │
└─────────────────────────────────────┘
```

**关键认知**：真正导航是"建图→定位→全局→局部→控制"闭环。
- A* 只是"全局规划器"一个零件
- 没有定位，规划没意义（不知道自己在哪）
- 没有控制，路径只是图（不能执行）

## 三、路径规划算法分类

### 全局规划（已知地图，离线）

| 类 | 算法 | 特点 |
|---|---|---|
| **图搜索** | Dijkstra / A* / D* | 基于图，有最优性保证 |
| **采样** | RRT / RRT* / PRM | 随机采样，高维适用 |

### 局部规划（在线，实时避障）

| 算法 | 特点 |
|---|---|
| **DWA** | 速度空间采样，实时 |
| **TEB** | 时间弹性带，平滑 |
| **MPC** | 模型预测，最优 |

### 关键：全局 vs 局部分工

```
全局规划：已知地图，定"大方向"（A* 出全局路径）
局部规划：实时传感器，做"避障"（DWA 跟随路径+避开动态障碍）
```

**为什么需要两层**：
- 全局规划假设地图已知——但真实环境有动态障碍
- 局部规划只处理局部——需要全局路径指引方向
- **两层配合** = 完整导航（Nav2 就是这么做的）

## 四、MATLAB 仿真 vs 实际部署（关键认知）

### 为什么科研用 MATLAB？
MATLAB 有 Navigation Toolbox，算法封装好、数学验证方便、画图好——**算法验证**的理想工具。

### MATLAB vs ROS2 的本质区别

| | MATLAB 仿真 | ROS2 实际部署 |
|---|---|---|
| 算法 | 内置 Toolbox | Nav2 栈 / 手写 |
| 地图 | 理想已知 | 激光实时建 |
| 定位 | 假设已知 | AMCL 实时算 |
| 传感器 | 仿真 | 真实激光雷达 |
| 输出 | 路径图 | **控制指令给电机** |
| 本质 | **算法验证** | **完整系统** |

### 实际部署流程（Nav2）

```
激光雷达 → SLAM建图 → 栅格地图
目标点 → AMCL定位 → 全局A*路径 → 局部DWA避障 → 控制底盘
```
