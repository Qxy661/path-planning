# 08 · 手写 A* 集成 Nav2 全局规划插件

> 深度调研（2026-08）确认：**"手写路径规划算法 → Nav2 全局规划插件"是作品集可信度最高的模式**。
> 本文记录把本项目手写 A* 变成 Nav2 官方插件机制的完整过程与实测。

## 一、为什么做（调研依据）

多来源研究验证（官方 Nav2 插件教程 + 多个参考仓库 + 同行评审论文）：

| 依据 | 内容 |
|---|---|
| Nav2 官方文档 | `nav2_core::GlobalPlanner` 提供标准插件接口 |
| 参考实现 | mmcza/TurtleBot-RRT-Star、kuralme/path_planning_plugin、MiguelSolisSegura/nav2_dijkstra_planner 等 |
| 社区共识 | "手写算法换掉 Nav2 规划器"是系统集成能力的黄金证明 |

**意义**：从"会写算法"（Python demo）→"能进系统"（C++ 插件接入工业级导航框架），完成能力跃迁。

## 二、插件架构

```
┌─────────────────────────────────────────────────┐
│  Nav2 planner_server                              │
│  ├─ 读取 nav2_params.yaml 的 planner_plugins       │
│  └─ pluginlib 加载「astar_nav2_plugin/AstarPlanner」│
│       └─ 继承 nav2_core::GlobalPlanner            │
│            ├─ configure()    ← 拿代价地图指针/参数   │
│            ├─ createPlan()   ← 手写 A* 图搜索       │
│            └─ PLUGINLIB_EXPORT_CLASS 导出          │
└─────────────────────────────────────────────────┘
```

**五个标准接口**（`nav2_core::GlobalPlanner`）：
`configure` / `activate` / `deactivate` / `cleanup` / `createPlan`

**关键设计**：
- 代价地图 → 0/1 二值栅格（障碍阈值可配置，默认 253 = 只挡内切/致命障碍）
- 8 邻域 A* + 欧氏启发式（保证最优）
- createPlan 时**重新读取** costmap origin/resolution（configure 时地图可能未加载）
- 起点/终点落在障碍上时回退到最近空闲格

## 三、使用

```bash
# 1. 构建插件
cd nav2_astar_plugin
colcon build --packages-select astar_nav2_plugin
source install/setup.bash

# 2. 用插件配置启动 Nav2（nav2_astar_params.yaml 已切换规划器）
ros2 launch turtlebot3_navigation2 navigation2.launch.py \
  map:=~/map/room.yaml \
  params_file:=robot/config/nav2_astar_params.yaml \
  use_sim_time:=True

# 3. 导航（插件作为全局规划器工作）
python3 robot/nav_goal.py 1.5 1.5
```

**切换回默认规划器**：把 `nav2_astar_params.yaml` 的 `GridBased.plugin` 改回 `nav2_navfn_planner/NavfnPlanner` 即可——**配置即切换，零代码改动**。

## 五、踩坑记录

| # | 问题 | 解决 |
|---|---|---|
| 1 | CMake 缺 `install(TARGETS)`，库构建了但没安装 | 加 install 规则 |
| 2 | configure 时 costmap origin 是 (0,0)（地图未加载）| createPlan 时**重新读取** origin/resolution |
| 3 | 障碍阈值 200 太保守，膨胀代价地图导致间歇不可达 | 阈值改 253（只挡内切/致命障碍），规划成功率 →96.8% |
| 4 | Humble 的 params 在 `param/humble/`，非 `param/` | 基于正确版本生成配置 |
