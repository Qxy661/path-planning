# 03 · 局部规划算法（DWA / TEB）

> 局部规划：在线实时避障，吃实时传感器数据，输出速度指令。
> 全局规划给"方向"，局部规划做"避障"。
> 配套代码：`algorithms/dwa.py`。

## 一、为什么需要局部规划

```
全局规划(A*)：已知地图 → 全局路径（假设环境不变）
但真实环境：有移动障碍、地图不完美
局部规划：实时看传感器 → 避开动态障碍 + 跟随全局路径
```

**核心**：全局规划是"战略"（大方向），局部规划是"战术"（实时避障）。

## 二、DWA（Dynamic Window Approach）动态窗口法

### 核心思想
**在速度空间采样**，用轨迹预测评估，选最优速度执行。

```
1. 动态窗口：根据当前速度和加速度限制，算出可达速度范围 (v, w)
2. 采样：在窗口内采样多组 (v, w)
3. 预测：对每组速度，模拟未来轨迹（predict_time 内）
4. 评估：对轨迹打分（目标/障碍/朝向）
5. 执行：选最高分的 (v, w)
```

### 评估函数（核心）
```
score = w_goal * 目标代价 + w_obs * 障碍代价 + w_heading * 朝向代价
```

| 代价 | 意义 |
|---|---|
| **目标代价** | 轨迹终点离目标多远 |
| **障碍代价** | 轨迹离障碍多近（越近分越差）|
| **朝向代价** | 车头方向与目标方向夹角 |

**加权调参**：
- 想快速到目标 → 加大 w_goal
- 怕撞 → 加大 w_obs
- 平滑转向 → 加大 w_heading

### 关键：动态窗口
```
[v_min, v_max] = [v - accel*dt, v + accel*dt]  # 加速度限制
[w_min, w_max] = [w - dyaw*dt, w + dyaw*dt]
```
**只在"能到达的速度"里采样**（动态窗口），保证规划可行。

## 三、DWA vs TEB

| | DWA | TEB |
|---|---|---|
| 方式 | 速度空间采样 | 时间弹性带优化 |
| 输出 | (v, w) | 轨迹（带时间）|
| 平滑 | 一般 | 好（考虑约束）|
| 计算 | 快 | 较重 |
| 适用 | 快速实时 | 平滑/多约束 |

## 五、DWA 在 Nav2 的角色

```
全局路径(A* 出的点序列)
    ↓
局部规划器(DWA/DWB) 每个控制周期：
  看局部地图(代价地图) + 目标路径点
  → 采样速度 → 选最优 → 发 /cmd_vel
```

Nav2 的局部规划器默认是 DWB（DWA 变体），
**手写 DWA 对比它 = 探索应用**。

## 六、与全局规划的配合（关键）

```
局部规划不能独立工作：
  没有全局路径 → 局部规划不知道"大方向"，会绕圈/卡住
  只有全局路径 → 遇到动态障碍会撞
两层配合：
  全局 A*：给出通往目标的路径骨架
  局部 DWA：实时避开障碍，跟随骨架前进
```

## 七、调参经验

| 场景 | 调整 |
|---|---|
| 目标被障碍挡住 | 加大 w_goal，或加大 predict_time |
| 转不过弯 | 加大 max_yaw_rate，减小 max_speed |
| 撞障碍 | 加大 w_obs，加大 obstacle_radius |
| 抖/来回 | 减小 max_accel，加大 dt |
